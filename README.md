# Portfolio - YEVI Mawuli Péniel Samuel

Site web personnel et portfolio statique, hébergé sur GitHub Pages et accessible à l'adresse [leumas-nedlog.me](https://leumas-nedlog.me).

## Présentation

Ce dépôt contient le code source du portfolio de YEVI Mawuli Péniel Samuel, étudiant en systèmes embarqués et IoT à l'IFRI-UAC et chercheur autodidacte en informatique scientifique, programmation systèmes et modèles d'IA locaux.

## Structure du projet

- `index.html` : Structure sémantique de la page unique et intégration des projets.
- `assets/css/style.css` : Feuille de style CSS consolidée (variables, responsive, éditeurs de code).
- `assets/img/` : Ressources graphiques, logos et captures d'écran des projets.
- `CNAME` : Configuration du domaine personnalisé.
- `robots.txt` : Directives d'indexation pour les moteurs de recherche.
- `sitemap.xml` : Plan du site pour le référencement naturel (SEO).

## Projets mis en valeur

1. **Bissi** : Agent d'IA local-first et 100% hors ligne (Gemma 4 E2B fine-tuné avec Unsloth, quantifié en Q4_K_M).
2. **Mercuria** : Environnement d'expérimentation scientifique orienté preuve (Rust, Tauri v2).
3. **Elementals** : Langage de programmation pour le calcul multi-dimensionnel compilé via LLVM IR (OCaml).
4. **logariasmós (numc)** : Bibliothèque de calcul scientifique modulaire en C11 (gestion mémoire stricte, Valgrind).
5. **Automaton Universale** : Framework déclaratif pour l'IA embarquée et le contrôle cyber-physique (Python).
6. **Graphy** : Bibliothèque formelle de théorie des graphes et algorithmique.
